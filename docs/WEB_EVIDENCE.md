# 网页来源、时间口径与公开披露联调

参考资料库可以导入公开 HTTPS HTML/PDF 网址；新建复核也可勾选“读取报告引用网址”，支持正文直链和 `[S1]: https://...` 参考定义。抓取成功的资料与所选资料版本合并，发布本次独立知识库版本。抓取失败会保存错误，不填充演示内容；该引用不能自动通过。动态加载、需登录或禁止抓取的网页需提供可读文件。

网页原始响应和 SHA256、最终网址、每次重定向、抓取时间、HTML/JSON-LD 声明的发布时间/更新时间及其原文依据一起保存。父子块携带数据期间、数据时点、期间判断依据和多期间歧义标记；网页 v2 解析器区分同一段中的公告发布日期与 quarter ended 数据日期。旧快照不回写。相同响应和解析器版本可复用，内容变化或解析器升级生成新的登记资料。

资料进入真实 m3e/BM25/RRF/bge 重排链路；报告引用的文档另作范围内召回，避免只验证了其他来源而忽略原引用。中英文常见企业、财务指标查询扩展会保存映射版本、原查询和扩展查询。模型评分和最终引用必须逐字匹配原文；未验证行列绑定的多期间表格仍交人工。

逐项复核中，PDF 原页与网页快照共用来源证据区。网页在隔离的阅读框内显示保存版本，支持父块定位、引用原文和用户关键词高亮；来源脚本、外部 iframe、表单和事件属性不执行；可取得的样式和图片经过公开地址验证后本地缓存。链接悬停显示摘录，点击报告旁证据链接在本工作台证据区查看，当前原网页另有显式入口。绿色高亮仅代表字面匹配，不意味着支持结论。默认显示原始 DOM 及可取得样式，按原文定位高亮；“正文摘录”作为回退。依赖 JavaScript 或登录的动态内容可能缺失，不能保证网站交互的完整镜像。

时间校验独立于检索分数和语义相似度：

- `as_of` 为信息截止日；逐项明确“以 YYYY-MM-DD 为信息截止日”只会收紧截止日。
- `published_at`、`updated_at` 晚于截止日，不能用当前快照证明当时已知；缺少历史版本时判为证据不足。
- `data_period` 对齐财年/季度，期间不明或多期间表格未完成行列绑定时交人工。
- `data_period_start/end` 可要求明确的区间边界；当前状态模式还需数据时点及 `max_age_days`。
- `effective_from/to`、`superseded_by` 有值时检查生效、失效与更正关系。这些元数据须由来源/导入流程提供，系统不能自动掌握整个互联网的更正公告。
- `fetched_at` 仅表示抓取，不代替发布时间和数据期间。HTTP Last-Modified 仅保存为响应头，不冒充公告日期。
- PDF/文本文件可在上传时补充发布日期和数据期间结束日，底稿明确标记为人工提供。未知保持未知。

时效或引用失败不直接等同于数值矛盾。只有完成逐字引用、指标、币种、期间等绑定后，Decimal 才判定数值冲突。单一金额断言的全部绑定校验通过且主体/时间/引用都匹配时，程序可纠正模型的单位换算误判；复杂因果、偿债及风险断言不能由一个正确金额代替核验。

下载 HTML/PDF 保留时间/引用检查结果；底稿 ZIP 包含原始 HTML/PDF、净化阅读快照、元数据、父子块、固定版本、模型请求/响应、候选评分、计算和文件哈希清单。离线 HTML 链接指向安全阅读快照；原始响应仍保留在 sources 中供审计。哈希链不是外部可信时间戳。

## 测试与复现

`examples/web_review/mixed-report.md` 为真实公开披露基础上的刻意混合错误报告；`gold.json` 单独保存人工预期，禁止送入核验模型。16 项：4 项正确、五类问题各2项、2项时间/引用控制。它是开发联调集，经过针对通用工程缺陷的修复与重放，不是独立盲测。

```bash
PYTHONPATH=src HF_HUB_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  .venv/bin/python scripts/evaluate_web_review.py \
  --data-dir .local-data/web-eval --output .local-data/web-eval-results \
  --model claude-sonnet-4-6
```

`--model` 只在该次评测进程使用，不改 `.env`。不指定时用工作台配置；站点目录列出模型不保证接口当次可用。结果缓存可恢复；`--retry-errors` 只重试执行错误。`--recheck-numeric` 复用已审计的模型操作数，运行当前时间/引用和 Decimal 规则，保存重放前结果及新增底稿，不重写原始模型输出。

评测给定复核点边界，使用生产混合检索、评分、Verifier、时间/引用校验和数值校验；首次证据不足会补一次查询。不包含生产 Planning Agent 的语义查询规划，不代替报告抽取或完整人工恢复评测。`metrics.json` 分别记录执行完成率、问题/通过方向、主要标签命中、完整标签集合一致率、逐类 precision/recall。多标签会产生额外标签，不能把一个较高的二分类得分称作五类分类准确率。


## v2 检索规划、循环与标签

新建任务显式发送 `workflow_version: 2` 和 `web_search_enabled`。关闭公开搜索时仍执行 LLM 规划与本地 RAG。开启后先使用 LLM 生成的短查询进行公开搜索，再读取结果的真实 HTTPS HTML/PDF；搜索摘要只用于发现网址。所有请求受公开 IP、重定向、内容类型、字节、次数和超时限制。免费搜索接口可能受验证、地域或访问限制；失败保存底稿，不把无关结果冒充证据。

路由与检索规划分别是 `route_retrieval`、`plan_query` 节点。规划接收主体、来源格式、上一轮证据摘录、评分与 missing_needs。请求枚举与注册指标先校验，结构错误限1次修复；失败回退到明确记录的有限查询。每条结论最多2组查询、最多1轮补检索；全任务最多12次公开搜索与12份新增资料。新增资料建立真实向量索引并发布新版本，检索结果保留当轮 `retrieved_kb_version` 以及版本演进记录。

`classify_issues` 逐类做必要条件判断，再由独立复核智能体复查。只有两者一致且引用经校验的类别自动接受；分歧、非法引用或调用失败进入人工。结构或引用错误可按原始证据修复1次，不补造标签。风险遗漏限定于报告整体风险扫描或明确风险清单；一般结论的反向证据不会自动生成此标签。数值冲突与人工介入原因单独保存，不强塞进五类标签。

全部结论自动预检后，v2 将每个待办保存在对应结果的 `human_task` 内，`fact_id + task_version` 防止错项和重复提交。人工判定保存自动判定副本、采用证据、复核人、时间及理由；原始模型输出与底稿不改写。风险覆盖智能体异常或引用失败不会阻止其他结论预检，但会产生显式“风险覆盖未完成”人工待办。

网页原貌视图保留原始响应哈希和派生 HTML/资产清单，CSS 优先于字体缓存，最多20份/8MB资源。原站脚本禁用，仅允许固定哈希的本机定位脚本在不含 allow-same-origin 的沙箱运行。PDF 按物理页光栅化显示，引用与关键词只在本页真实匹配时标记；扫描件需 OCR 后才能文字定位。底稿 ZIP 可包含已生成的原貌视图及资产。

`scripts/evaluate_issue_agents.py` 可用冻结的已审计证据单独比较五类标签。它不重新测试抽取、规划、浏览器检索或人工流，也不是盲测；五类集合一致率不与包含额外事实冲突类别的旧六类集合指标直接比较。


## 业务验收以问题发现和报告完整性为主

五类问题允许多标签、归类交叉；标签集合完全一致保留为辅助诊断，不作为主要验收门槛。报告以自然语言说明每个实际问题、对应依据及需进一步核实的资料，不要求为每类问题额外提供细碎的词句级定位；来源页码、引用和底稿仍保留以供审计。

候选智能体和复核智能体对问题存在分歧时，报告仍列出“待确认”解释，不因类别未一致就隐藏候选问题，也不把它当作已确认错误。多个标签表达同一个问题时合并相同说明；程序计算出的数值冲突单独写清楚。报告引用同时包含这些问题实际采用的证据，分类放在辅助信息中。

主要指标分别是有问题复核点的召回、正常复核点通过/误报、执行失败，以及报告是否把一个复核点内的所有具体问题讲清楚。结论级命中不等于问题完整覆盖。`report-coverage-review.json` 列出标准问题描述、实际报告解释以及待人工检查项；未审阅时不授予报告完整性得分。`evaluate_issue_agents.py --rescore-only` 只重算已有预测，不调用模型、不改变原结果。
