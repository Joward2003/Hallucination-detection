## 重要交互修复

- 高风险筛选包含严重风险；空筛选结果不再继续显示被排除的结论。
- 前后项切换遵循当前筛选结果；切换后从判定依据顶部阅读。
- 筛选、原文对照和证据切换后保留未提交的理由、所选证据、修订内容和判定。
- 同一 evidence_id 重复返回时只展示一次。
- 证据缺口优先显示需求描述，不直接把内部编号交给业务人员。
- 取消、失败、中断与完成的任务不再展示可提交的人工判定表单。
- API 连接成功后以服务端任务为准；保留真实任务名称与创建时间。
- 检索相关度和模型置信度明确标注为“非正确率”。
