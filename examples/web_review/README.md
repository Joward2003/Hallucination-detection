# 公开披露混合错误样本

这是使用真实公开信息设计的测试报告，**含刻意错误，不可作为真实授信建议**。来源为微软2025/2024财年第四季度新闻稿，以及苹果2025财年第三季度中文新闻稿；原始链接位于报告末尾。

- C01–C04：正确陈述。
- E01–E02：缺少证据的债务/收款断言。
- E03–E04：数值正确但引用企业错误。
- E05–E06：表述过强。
- E07–E08：推理跳跃。
- E09–E10：各段风险清单遗漏披露的重要风险。
- T01：引用错财年；T02：采用早于发布日的单项信息截止日。

`gold.json` 为人工编写的预期，独立于模型输出。风险遗漏单项按该段风险清单评估；完整报告另做整体风险覆盖检查，两种统计不能混为一谈。4个正确项是有限来源范围内的正确控制，不代表完整授信尽调。

苹果当前网页声明了晚于原公告的更新时间，因此默认用2026-10-16信息截止日；不能用该当前快照证明2025年当时已知。T02刻意使用更早截止日。

真实 API 评测会发生模型调用，配置、原始输出、失败、检索和重放结果均保存底稿。详见 `docs/WEB_EVIDENCE.md`。
